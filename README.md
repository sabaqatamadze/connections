# 🌍 Connections — Travel & Tourism Website

A modern, responsive tourism website designed to showcase travel experiences, tour packages, and destinations in Georgia.

The project focuses on creating a clean and engaging experience for visitors while making it easy to explore available packages and contact the business.

## 🌐 Live Website

**Website:**
https://connectionsge.com

**GitHub:**
https://github.com/sabaqatamadze/connections

## ✨ Features

* 🏔️ Tourism and travel-focused landing page
* 🗺️ Tour and destination information
* 📦 Travel packages

## 🏠 Main Sections

### Hero Section

A visually focused landing section introducing the tourism business and giving visitors a quick overview of the available experiences.

### About

Provides information about the company and its approach to tourism.

### Packages

Displays available travel packages with relevant information such as:

* Package name
* Description
* Price
* Included experiences
* Package details

### Destinations & Experiences

The website highlights different locations and experiences to help visitors discover what the business offers.

### Contact

A contact section allows visitors to get in touch with the business.

The project is structured so that contact information and communication features can be easily maintained and extended.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sabaqatamadze/connections.git
```

Enter the project:

```bash
cd connections
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local development URL in the terminal.

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 🚀 Deployment

The frontend is deployed using **Vercel**.

Production deployment is connected to the GitHub repository, allowing the project to be built and deployed through Vercel.

Live website:

https://connectionsge.com

---

## 🔌 Backend & API

The frontend communicates with backend/API services to handle dynamic website data.

API-related functionality is separated from UI components to keep the project organized and make future changes easier.

This approach allows the frontend to consume dynamic information instead of hard-coding everything directly into the components.
